# kleinia-os/.github

Organization-wide defaults for [Kleinia](https://kleinia.io).

- `profile/README.md`: the page shown at <https://github.com/kleinia-os>
- `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`, `SUPPORT.md`:
  default community health files. GitHub shows them in every public repo that
  doesn't have its own copy.
- `ISSUE_TEMPLATE/`, `PULL_REQUEST_TEMPLATE.md`: default issue forms and PR template

A repository that needs something different should add its own file; the
repository's file wins over the one here.
