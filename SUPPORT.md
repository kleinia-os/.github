# Getting help with Kleinia

Pick the place that fits your question. You'll get a faster answer, and the
issue tracker stays usable for everyone.

| You want to… | Go to |
|---|---|
| Install Kleinia or learn how something works | [docs.kleinia.io](https://docs.kleinia.io) |
| Ask a question, share a setup or chat | [Discord](https://kleinia.io/discord) (`#help`) |
| Propose an idea that isn't ready to become an issue yet | [Discord](https://kleinia.io/discord) (`#feedback`) |
| Report a reproducible bug | An issue in the [relevant repository](https://github.com/kleinia-os); use [`kleinia`](https://github.com/kleinia-os/kleinia/issues/new/choose) if you're unsure |
| Report a security vulnerability | **security@kleinia.io**. See [SECURITY.md](SECURITY.md) |
| Reach the team about anything else | cjcongjia@zju.edu.cn |

## Before you open an issue

1. Search existing issues and the Discord `#help` forum; someone may have hit it already.
2. Note your image version (`rpm-ostree status` or `bootc status`) and the hardware involved.
3. If the problem started after an update, check whether rolling back fixes it
   (`rpm-ostree rollback`, then reboot), and say so in the report.

Kleinia is a young project run by a small team. We read everything, but we
can't promise a response time. Discord is where the community can help each
other too.
