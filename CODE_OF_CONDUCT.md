# Code of Conduct

Kleinia adopts the **[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)**
as the code of conduct for every space the project runs. Please read it in full;
this page only adds the details specific to Kleinia.

## Where it applies

All repositories, issues, pull requests and discussions under
[github.com/kleinia-os](https://github.com/kleinia-os), the Kleinia Discord
server, and any event or channel where you represent the project.

## In short

- Be kind and assume good intent. Many people here write in a second language.
- Critique code and ideas, never people.
- No harassment, discrimination, sexualised content, doxxing or personal attacks.
- Respect people's time: no spam, unsolicited DMs or self-promotion.
- Follow the maintainers' and moderators' requests; if you disagree, raise it in private.

## Reporting

Email **cjcongjia@zju.edu.cn**, or on Discord DM any member with the
**Moderator** role. Reports are read only by the maintainers and are handled
in confidence. If a maintainer is involved, say so and they will be excluded
from handling your report.

Enforcement follows the Contributor Covenant's
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines):
correction, warning, temporary ban, permanent ban.
